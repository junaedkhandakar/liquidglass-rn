Installation Guide

Get started in your Expo SDK 54 or React Native project in under a minute.

1. Install Dependencies

npx expo install liquidglass-rn @shopify/react-native-skia expo-blur react-native-reanimated react-native-gesture-handler react-native-svg lucide-react-native

2. Add Reanimated Babel Plugin

Ensure the plugin is added as the last item in your `babel.config.js`:

module.exports = function(api) {
  api.cache(true);
  return {
    presets: ['babel-preset-expo'],
    plugins: ['react-native-reanimated/plugin'],
  };
};

3. Wrap Application Root

import { GestureHandlerRootView } from 'react-native-gesture-handler';
import { LiquidThemeProvider } from 'liquidglass-rn';

export default function App() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <LiquidThemeProvider defaultMode="system">
        <YourApp />
      </LiquidThemeProvider>
    </GestureHandlerRootView>
  );
}
